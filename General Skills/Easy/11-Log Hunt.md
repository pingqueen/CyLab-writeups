#### متن سؤال:
به نظر می‌رسد سرور ما بخش‌هایی از یک فلگ محرمانه را در فایل‌های Log فاش می‌کند.

قطعه‌های فلگ در قسمت‌های مختلف فایل پراکنده شده‌اند و بعضی از آن‌ها چند بار تکرار شده‌اند. آیا می‌توانیم قطعه‌های اصلی را پیدا کنیم، موارد تکراری را حذف کنیم و فلگ کامل را دوباره بسازیم؟

برای حل چالش، فایل Log را دانلود می‌کنیم:

```text
server.log
```

#### سرنخ‌ها:
می‌توان از دستور `grep` برای نمایش فقط خط‌هایی استفاده کرد که با یک عبارت مشخص مطابقت دارند.

بعضی از خط‌ها تکراری هستند؛ بنابراین باید نمونه‌های اضافه را نادیده بگیریم.
***
#### مراحل حل:
ابتدا باید داخل فایل Log به‌دنبال عبارت‌هایی بگردیم که احتمال می‌دهیم بخشی از فلگ باشند.

از آنجا که فلگ‌های picoCTF معمولاً با عبارت زیر شروع می‌شوند:

```text
picoCTF{
```

دستور زیر را اجرا کردیم:

<img width="471" height="194" alt="image" src="https://github.com/user-attachments/assets/b31de0cd-456f-4f5e-b0c5-701b1867dcca" />

مشاهده کردیم یک قطعه چند بار در زمان‌های مختلف تکرار شده است. پس باید تمام خط‌های مربوط به قطعه‌های فلگ را پیدا کنیم و تکرارها را حذف کنیم.

`نکته: دستور grep برای جست‌وجوی یک الگو یا عبارت داخل فایل‌ها استفاده می‌شود و فقط خط‌های مطابق را نمایش می‌دهد. و در این دستور -i باعث می‌شود جست‌وجو نسبت به حروف بزرگ و کوچک حساس نباشد.`

در خروجی فایل مشخص بود که خط‌های موردنظر شامل عبارت زیر هستند:

```text
FLAGPART:
```

بنابراین برای فیلترکردن آن‌ها از دستور زیر استفاده کردیم و برای بررسی حذف خطوط تکراری، خروجی را به `sort -u` ارسال کردیم:

<img width="495" height="570" alt="image" src="https://github.com/user-attachments/assets/f8ae0c85-f849-4bea-a9c4-fe15ea4a0a35" />

`نکته: گزینه -u در دستور sort مخفف unique است و خطوط کاملاً یکسان را فقط یک بار نگه می‌دارد.`

با این حال، این روش در اینجا مشکل را کامل حل نمی‌کند؛ زیرا هر خط شامل Timestamp متفاوتی است.

برای مثال دو خط زیر یک قطعه فلگ یکسان دارند، اما به‌دلیل متفاوت‌بودن زمان، از دید `sort -u` دو خط متفاوت هستند:

```text
[1990-08-09 10:10:54] INFO FLAGPART: cedfa5fb}
[1990-08-09 10:10:58] INFO FLAGPART: cedfa5fb}
```

بنابراین قبل از حذف تکرارها باید اطلاعات اضافی ابتدای هر خط را حذف کنیم و فقط خود قطعه فلگ را نگه داریم.

`نکته: sort -u علاوه بر حذف خطوط تکراری، آن‌ها را مرتب می‌کند. در این چالش ترتیب قطعه‌ها مهم است؛ بنابراین مرتب‌سازی الفبایی می‌تواند ترتیب اصلی فلگ را نیز خراب کند.`

برای استخراج قطعه‌ها، حذف تکرارها با حفظ ترتیب و چسباندن آن‌ها به یکدیگر، دستور زیر را اجرا کردیم:

<img width="377" height="128" alt="image" src="https://github.com/user-attachments/assets/d8c0543c-930b-405e-a862-fa9d5dd5611a" />

بخش اول دستور:

```bash
grep 'FLAGPART' server.log
```

فایل `server.log` را می‌خواند و فقط خط‌هایی را نمایش می‌دهد که شامل عبارت `FLAGPART` هستند.

برای مثال:

```text
[1990-08-09 10:00:10] INFO FLAGPART: picoCTF{us3_
[1990-08-09 10:02:55] INFO FLAGPART: y0urlinux_
```
خروجی `grep` با Pipe به دستور `sed` ارسال می‌شود:

```bash
sed 's/.*FLAGPART: //'
```

دستور `sed` برای ویرایش و تبدیل متن به‌صورت خطی استفاده می‌شود.

ساختار جایگزینی در `sed` به‌شکل زیر است:

```text
s/عبارت-موردنظر/متن-جایگزین/
```

در دستور ما:

```text
s/.*FLAGPART: //
```

بخش زیر:

```text
.*
```

یعنی هر تعداد کاراکتر از ابتدای خط.

بنابراین الگوی زیر:

```text
.*FLAGPART: 
```

تمام متن از ابتدای خط تا انتهای عبارت `FLAGPART: ` را انتخاب می‌کند.

از آنجا که قسمت جایگزین خالی است، این بخش حذف می‌شود و فقط خود قطعه فلگ باقی می‌ماند.

برای مثال:

```text
[1990-08-09 10:00:10] INFO FLAGPART: picoCTF{us3_
```

به این تبدیل می‌شود:

```text
picoCTF{us3_
```

`نکته: حرف s در دستور sed مخفف substitute است؛ یعنی متن مطابق الگو را با مقدار دیگری جایگزین کن.`

در مرحله بعد از دستور زیر استفاده شده است:

```bash
awk '!seen[$0]++'
```

دستور `awk` یک ابزار پردازش متن است که می‌تواند هر خط را به‌صورت یک رکورد بررسی کند.

در `awk` متغیر زیر:

```text
$0
```

به کل خط فعلی اشاره می‌کند.

عبارت:

```awk
seen[$0]
```

یک آرایه به نام `seen` ایجاد می‌کند که خط‌های مشاهده‌شده را ذخیره می‌کند.

در اولین باری که یک خط دیده می‌شود، مقدار آن هنوز صفر است:

```text
seen[$0] = 0
```

علامت `!` مقدار صفر را به True تبدیل می‌کند؛ در نتیجه خط چاپ می‌شود.

سپس عملگر زیر مقدار شمارنده را افزایش می‌دهد:

```text
++
```

اگر همان خط دوباره دیده شود، مقدار آن قبلاً بیشتر از صفر شده است و شرط False می‌شود؛ بنابراین خط تکراری چاپ نخواهد شد.

مزیت مهم این روش نسبت به `sort -u` این است که ترتیب اولین مشاهده هر قطعه را حفظ می‌کند.

قطعه‌های یکتا به‌ترتیب زیر باقی می‌مانند:

```text
picoCTF{us3_
y0urlinux_
sk1lls_
cedfa5fb}
```
در مرحله قبل، هر قطعه در یک خط جداگانه قرار دارد. برای چسباندن آن‌ها به یکدیگر از دستور زیر استفاده می‌شود:

```bash
tr -d '\n'
```

دستور `tr` مخفف translate است و برای تبدیل یا حذف کاراکترها استفاده می‌شود.

گزینه زیر:

```text
-d
```

مخفف `delete` است؛ یعنی کاراکتر مشخص‌شده را حذف کن.

کاراکتر زیر:

```text
\n
```

نماینده Newline یا رفتن به خط بعدی است.

پس این دستور تمام Line Breakها را حذف می‌کند و قطعه‌ها را کنار هم قرار می‌دهد.

پس از پایان Pipeline از دستور زیر استفاده شده است:

```bash
echo
```

چون `tr -d '\n'` آخرین کاراکتر خط جدید را نیز حذف می‌کند، Prompt ترمینال ممکن است بلافاصله پس از فلگ ظاهر شود.

دستور `echo` یک خط جدید چاپ می‌کند تا خروجی خواناتر باشد.

علامت زیر بین `tr` و `echo` قرار دارد:

```text
;
```

در Shell، `;` جداکننده دستورها است؛ یعنی ابتدا دستور سمت چپ را اجرا کن و پس از پایان آن، دستور سمت راست را اجرا کن.

فلگ نهایی:

```text
picoCTF{us3_y0urlinux_sk1lls_cedfa5fb}
```
