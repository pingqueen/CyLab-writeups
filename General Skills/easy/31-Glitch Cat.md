#### متن سؤال:
سرویس چاپ فلگ دچار اختلال شده است!

برای اتصال به سرویس باید از Netcat استفاده کنیم:

```text
nc saturn.picoctf.net 53079
```


#### سرنخ‌ها:
حالت `ASCII` یکی از رایج‌ترین روش‌های نمایش کاراکترها در برنامه‌نویسی است.

خروجی خراب‌شده سرویس، با وجود ظاهر غیرعادی، یک عبارت معتبر Python است.

برای قطع اتصال Netcat و بازگشت به Shell می‌توانیم از کلیدهای زیر استفاده کنیم:

```text
Ctrl + C
```
***
#### مراحل حل:
ابتدا با دستور زیر به سرویس چالش متصل شدیم؛ پس از اتصال، سرویس به‌جای چاپ مستقیم فلگ، عبارت زیر را نمایش داد:

<img width="1277" height="80" alt="image" src="https://github.com/user-attachments/assets/41b0d0f6-f61f-4020-8041-f57ec9c609ba" />

`نکته: دستور nc مخفف Netcat است و برای برقراری ارتباط مستقیم با یک سرویس شبکه‌ای روی Host و Port مشخص استفاده می‌شود.`

به‌جای تبدیل دستی، می‌توانیم آن را با Python اجرا کنیم.

<img width="1280" height="70" alt="image" src="https://github.com/user-attachments/assets/61ee0b97-680d-4ef4-91c1-57cad182d247" />

`نکته: دستور python3 برای اجرای مفسر زبان برنامه‌نویسی Python 3 و اجرای فایل‌های پایتون در ترمینال استفاده می‌شود.`

`نکته: گزینه -c در دستور python3 برای اجرای مستقیم یک قطعه کد پایتون داخل ترمینال استفاده می‌شود؛ یعنی بدون ساختن فایل .py.`

`نکته: تابع chr() در پایتون یک عدد را به کاراکتر Unicode متناظر آن تبدیل می‌کند. این عدد می‌تواند به‌صورت ده‌دهی یا هگزادسیمال نوشته شود.`

`نکته: تابع print() در پایتون برای نمایش متن، عدد، مقدار متغیر یا نتیجه یک عبارت در خروجی ترمینال استفاده می‌شود.`
