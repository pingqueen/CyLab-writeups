#### متن سؤال:
اسکریپت Python با نام زیر را اجرا کنید تا فلگ نمایش داده شود:

```text
runme.py
```

می‌توانیم فایل را با مرورگر دانلود کنیم یا در محیط Webshell با دستور `wget` آن را دریافت کنیم.

#### سرنخ‌ها:
اگر Python روی سیستم نصب باشد، می‌توانیم اسکریپت را به‌صورت عادی دانلود و اجرا کنیم.

در Webshell نیز می‌توانیم آدرس فایل را کپی کرده و با دستور زیر آن را دانلود کنیم:

```bash
wget LINK
```

پس از دانلود، برای اجرای برنامه از دستور زیر استفاده می‌کنیم:

```bash
python3 runme.py
```
