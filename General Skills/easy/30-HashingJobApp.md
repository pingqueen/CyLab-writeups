#### متن سؤال:
اگر می‌خواهید در محاسبه Hash بهترین باشید، این آزمون را پشت سر بگذارید!

برای شروع چالش باید با استفاده از Netcat به سرویس زیر متصل شویم:

```text
nc saturn.picoctf.net 57220
```

#### سرنخ‌ها:
برای محاسبه Hash متن می‌توانیم از ابزارهای خط فرمان یا یک Web App استفاده کنیم.

برای بستن اتصال Netcat و برگشتن به Prompt می‌توانیم کلیدهای زیر را فشار دهیم:

```text
Ctrl + C
```

***

#### مراحل حل:
ابتدا با دستور زیر به سرویس چالش متصل شدیم:

<img width="1280" height="362" alt="image" src="https://github.com/user-attachments/assets/d19d18de-82bd-439f-9feb-64b02c04c365" />

پس از اتصال، برنامه سه عبارت مختلف نمایش داد و برای هرکدام MD5 خواست.

`نکته: nc مخفف Netcat است و برای برقراری ارتباط مستقیم با یک سرویس شبکه‌ای روی Host و Port مشخص استفاده می‌شود.`

برنامه اول نمایش داد:

```text
Please md5 hash the text between quotes, excluding the quotes: 'Alfred Hitchcock'
```

یعنی باید عبارت زیر را Hash کنیم:

```text
Alfred Hitchcock
```

بدون اینکه علامت‌های `'` وارد داده شوند.

برای محاسبه MD5 از دستور زیر استفاده کردیم:

```bash
echo -n 'Alfred Hitchcock' | md5sum
```
برنامه دوم عبارت زیر را درخواست کرد:

```text
a morgue
```

دستور محاسبه:

```bash
echo -n 'a morgue' | md5sum
```
عبارت سوم:

```text
Cindy Crawford
```

دستور:

```bash
echo -n 'Cindy Crawford' | md5sum
```
`نکته: دستور echo برای چاپ متن، مقدار متغیر یا نتیجه یک عبارت در ترمینال استفاده می‌شود.`

`نکته: دستور echo به‌صورت پیش‌فرض بعد از متن، یک کاراکتر خط جدید (\n) نیز اضافه می‌کند. دستور echo -n مانند echo متن را چاپ می‌کند، اما گزینه -n مانع اضافه‌شدن خط جدید در انتهای متن می‌شود.`

`نکته: دستور md5sum برای محاسبه مقدار هش MD5 یک فایل یا داده استفاده می‌شود. خروجی MD5 یک رشته هگزادسیمال ۳۲ کاراکتری است.`

`نکته: MD5 یک الگوریتم هش‌سازی است که داده را به یک خروجی ثابت ۱۲۸ بیتی یا ۳۲ کاراکتر هگزادسیمال تبدیل می‌کند. هش با رمزگذاری تفاوت دارد و قابل رمزگشایی مستقیم نیست؛ اما MD5 به‌دلیل آسیب‌پذیری در برابر Collision، برای کاربردهای امنیتی حساس مناسب نیست.`
