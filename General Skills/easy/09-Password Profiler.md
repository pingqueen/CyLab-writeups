#### متن سؤال:
ما یک فایل مشکوک را از یک سیستم رهگیری کرده‌ایم، اما این فایل به‌جای خود رمز عبور، فقط هش `SHA-1` آن را در اختیار ما قرار می‌دهد.

با استفاده از تکنیک‌های `OSINT`، اطلاعات شخصی هدف در اختیار ما قرار گرفته است. وظیفه ما این است که با استفاده از این اطلاعات، یک فهرست رمز عبور اختصاصی یا **Custom Wordlist** بسازیم و رمز اصلی را با مقایسه هش آن بازیابی کنیم.

فایل‌های زیر برای حل چالش در اختیار ما قرار دارند:

```text
userinfo.txt
hash.txt
check_password.py
```

- فایل `userinfo.txt` شامل اطلاعات شخصی هدف است.
- فایل `hash.txt` شامل هش `SHA-1` رمز عبور است.
- فایل `check_password.py` رمزهای موجود در Wordlist را آزمایش می‌کند.

#### سرنخ:
ابزار `CUPP` یک ابزار پایتونی برای تولید Wordlist اختصاصی با استفاده از اطلاعات شخصی افراد است.

کد اسکریپت به‌صورت زیر عمل می‌کند:

در ابتدای برنامه، کتابخانه `hashlib` وارد شده است:

```python
import hashlib
```

این کتابخانه امکان محاسبه هش‌هایی مانند `SHA-1`، `SHA-256` و `MD5` را در Python فراهم می‌کند.

در ادامه، نام فایل هش و Wordlist مشخص شده است:

```python
HASH_FILE = "hash.txt"
WORDLIST_FILE = "passwords.txt"
```

بنابراین اسکریپت انتظار دارد:

- هش هدف داخل فایل `hash.txt` باشد.
- رمزهای احتمالی داخل فایل `passwords.txt` قرار داشته باشند.

تابع `load_hash()` فایل هش را باز می‌کند:

```python
with open(HASH_FILE, "r") as f:
    return f.read().strip()
```

حالت `"r"` یعنی فایل فقط برای خواندن باز می‌شود. متد `strip()` نیز فاصله‌ها و کاراکتر خط جدید ابتدا و انتهای متن را حذف می‌کند.

تابع `crack_password()` فایل Wordlist را خط‌به‌خط بررسی می‌کند:

```python
for password in f:
```

هر خط به‌عنوان یک رمز احتمالی در نظر گرفته می‌شود. سپس رمز به بایت تبدیل شده و هش `SHA-1` آن محاسبه می‌شود:

```python
hashlib.sha1(password.encode()).hexdigest()
```

- متد `encode()` رشته را به بایت تبدیل می‌کند.
- تابع `sha1()` هش SHA-1 داده را محاسبه می‌کند.
- متد `hexdigest()` نتیجه را به‌صورت یک رشته هگزادسیمال نمایش می‌دهد.

اگر هش رمز احتمالی با هش هدف برابر باشد، همان رمز بازگردانده می‌شود:

```python
if hashlib.sha1(password.encode()).hexdigest() == target_hash:
    return password
```

در نهایت، اسکریپت رمز پیدا‌شده را داخل قالب فلگ قرار می‌دهد:

```python
print(f"Password found: picoCTF{{{result}}}")
```
